Appointment Booking (GRT TECH prototype)

How to run: unzip, then double-click index.html (opens in any modern browser).
No install or server needed.

Notes:
- Data is saved in your browser (localStorage) only.
- The QR pass uses a library loaded from the internet (cdnjs). Without a
  connection the pass shows the reference number instead.
- Payments are simulated; email, SMS and video links are not configured.
- Admin tab: "Load demo data" fills the analytics with sample bookings.
